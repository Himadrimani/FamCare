Problem Statement - Families miss out to stay updated about each other's wellbeing, due to busy schedule and physical distance, leading to gaps in timely care and support.
App as a Solution - A calm and playful space where families can see each others vital to stay assured, support one another by planning care and curate their own fun challenges.

MVP Features:
1. Vital Sign Monitoring - This feature monitors vitals and activites using Apple Health Kit. The vitals which we fetch in our app are - Heart rate, Heart Rate Variation, spo2, respiratory rate. In activities - Steps, Distance Covered, Calories Burned.

2. Insights - This feature gives daily, weekly and monthly performance(based on vitals and activites being monitored) of each family member. Secondly, it compares the current with previous performance (ex- Dad's sleep hour has improved from last week).

3. Challenge - This feature allows families to curate their own EVENT or ACTVITY type challenges. Activity challenge may include customizing step goal for the challenge, calories burned, distance covered (goals differ from members to member as per their age). Events are the emotional ones, ex - Family movie night.

4. Message Area - This feature allows family members to send empathy driven message to each other. If someone in family in not well, he/she can get more care and support from others. Ex - If mom is unwell, others can plan out something for her.
